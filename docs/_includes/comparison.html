/01 — A decision, taken apart

A refund request is not refund authority.

Illustrative design.
Not measured performance.

  1. 01 / Observed evidence

    The request

    “I was charged twice.”

    No order ID is included. The customer’s message is evidence of intent, not proof of a duplicate charge.

  2. 02 / Model judgment

    Identify intent

    Choose a known category or abstain. Recognizing a refund request does not establish which charge is eligible.

    Output: a category, not permission.

  3. 03 / Explicit policy

    Hold the action

    A missing order ID requires authenticated lookup or a question to the customer. Do not guess the target.

  4. 04 / Code + authorized owner

    Check before paying

    Verify ownership, eligibility, amount, permissions, prior refunds, and idempotency before any refund executes.
