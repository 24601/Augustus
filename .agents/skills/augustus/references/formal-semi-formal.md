# Formal / semi-formal — one screen

Canonical card: `formal-methods.md`. This file is the executive
placement (curriculum `FORMAL-METHODS-1PAGER.md`, archived under
`research/archive/curriculum/`). Do not treat it as a second doctrine.

**Claim.** Formal and semi-formal methods own **precise models and
checks**. System One (Jev-class: Choice / Score / Noul) owns **fast
semantic estimates**. **Code owns policy.** Compose them. Do not
launder one as the other.

```text
proof / MC / contracts   →  exhaustive over a model or fragment
DST / PBT                →  searchlight; a seed is gold; absence is not proof
judgment-class model     →  belief about a given state
code / policy            →  actuator, authorization, stop-criteria
```

**Crossover intuition.** NATM gauges ≠ structural lining. Snap-fit
tolerances ≠ "feels clicked." Norman evaluation gulf ≠ execution gulf.
STAMP sensors ≠ safety constraints. Shirky situated loops ≠ Web-scale
proof. Kent: naming is the ontology. Soft judgment = observational
design; FM/code = load-bearing ring.

**Help.** Candidate properties/oracles (always run the checker);
filter before expensive MC/proof; triage CEXs / Alloy instances /
Antithesis timelines; rank lemmas/repairs; UI for specs; runtime
monitors + conformal abstention; fill ADRs and decision tables.

**Harm.** Noul as proof. Hard safety gate on a Noul (**TOCTOU-of-Noul**).
Tautological/vacuous specs (Hillel vibing specs; Cauli effort-curves).
Proof of the wrong ontology (Kent). Alloy ≠ Apalache. Score unit fiction.
Independence fiction. DST coverage as verification of unstated props.
PufferLib reward laundering. Silent Dafny/Lean edits that "make the
proof pass."

**Alloy vs Apalache (non-negotiable).** Alloy Analyzer = relational
**model finder** (SAT, finite scope). Apalache = **symbolic model
checker for TLA+** (SMT; BMC / random-exec / inductiveness). TLC
enumerates TLA+ explicitly. A Noul "this spec looks right" sits in
none of those seats.

**DST trio.** Antithesis = deterministic hypervisor + properties.
Resonate HQ = **durable async execution** (Distributed Async Await) —
Lean 4 abstract machine + differential oracle + SDK DST; not an
unrelated "Resonate AI" brand; promises settle in protocol, not via
Noul. PufferLib = env-as-sim; Ocean is a trainer contract, not a
comparative baseline; soft curriculum/done/triage only beside hard
probes.

**AI×FM.** Amazon TLA+ as exhaustively testable pseudo-code (code ≠
spec). Lamport Agent drafts; human validates. Quint `run` ≠ `verify`.
Hillel: LLMs write weak/tautological properties. Cauli: cost of
*something that typechecks* collapsed; cost of **strong properties +
non-vacuous models** did not. System One helps the *workflow around*
FM. It must not mint fake strength.
