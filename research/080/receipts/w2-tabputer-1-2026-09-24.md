## The one allowlist edit, and why

The proxy refused `api.github.com`, logged verbatim:

```
{"host": "api.github.com", "reason": "not_allowlisted", "target": "api.github.com:443",
 "ts": "2026-09-24T14:49:45Z", "verdict": "deny"}
```

Cause: Hugging Face's `refs/convert/parquet` for BANKING77 returns 404, and the dataset's pinned
loader points upstream. The CSVs were fetched from GitHub's raw Contents API at the **immutable
upstream commit** `57ec275d8078af65b7731c2a98be812d844a6d6b`, and **both CSV sizes and hashes match
the pinned HF `dataset_infos.json`**, which is what makes this a provenance-preserving fallback
rather than a different dataset. The entry was added from the refusal log, annotated with that
reason, and `augproxy` alone was reloaded. This is the documented procedure, and it is the only
allowlist change.

## Custody

At close, the data root was re-owned to root and re-ACLed for `augctl` only:

```
sudo chown -R root:root /srv/aug/quarantine/data
sudo setfacl -Rb /srv/aug/quarantine/data
sudo find /srv/aug/quarantine/data -type d -exec chmod 700 {} +
sudo find /srv/aug/quarantine/data -type f -exec chmod 600 {} +
sudo setfacl -m u:augctl:--x /srv/aug/quarantine
sudo find /srv/aug/quarantine/data -type d -exec setfacl -m u:augctl:r-x {} +
sudo find /srv/aug/quarantine/data -type f -exec setfacl -m u:augctl:r-- {} +
```

Readback: root-owned; `augctl` has `r-x` on directories and `r--` on files; group and other are
`---`. As `augexp`: `ls: cannot open directory /srv/aug/quarantine/data: Permission denied`, and
`head -c 0` on both the metadata and the actual `train.csv` denied. `augctl` read-only access
confirmed. `augctl` still has no subuid or subgid entries and ran only on the host.

## Stated caveats, kept rather than smoothed

- **The stage was not literally empty of row-shaped files.** It held M0b's synthetic fixtures
  (`m0b-fit/rows.json`, 1,252 bytes; `m0b-confirm/rows.json`, 297 bytes) and two fixture weight
  files. They were not opened; the identification rests on the M0b receipt. No experiment corpus
  was present, which is the claim that matters, but "no dataset at all" would have been wrong.
- The runner skipped the legacy full boundary scripts because they contain direct `nft` calls and
  memory/pid stress, and ran bounded network-only probes instead. That is the right call under the
  hard rules, and it means the post-close evidence is narrower than M0's.
- Minor operational notes recorded in the evidence file: recovered git permissions, a missing host
  library, a proxy startup race, and a raw-GitHub `Content-Type` assertion.
