# M5 design lock

Written against `plan-v4.md` at commit `0547e27`. M5 is the trainer reproduction: **which artifact
form is cheapest among those that meet the workload's own acceptance policy.** It tests claim P10
and, separately, P11.

| Field | Value |
| --- | --- |
| Estimand | The benchmark each task samples, at the declared independent unit: **one query** for T2a and T2b, **one comment** for T2c. The population is the benchmark, not deployment traffic, and the recipe says so |
| Comparator | R3a (SetFit, pinned body). Δ = loss(low rung) − loss(R3a) in normalized cost, so negative favours the low rung |
| Loss bound | Costs in [0, 1], so the paired difference has range **R = 2** |
| Method and mode | Empirical Bernstein, **one-sided non-inferiority**: UCB(Δ) < +0.01. Escalation uses the matching LCB at the same α/(2K) tail |
| Margin | **0.01**, kept from v1. Never widened |

## The family: K = 6

R1 (Qwen3.5-2B frozen readout: raw, two-order averaging, L0, then OOF temperature), R2a (LR on
MiniLM), R2b (ridge/LDA on R1's ⅔-depth state), **A1** (agent-synthesized program, frozen and
hashed before any confirmation read), **A2a** (PAW-standard via the local single-GPU compiler),
**A2b** (PAW-ft with a local teacher and a local initial compile).

A2a is inside the family because it is a tested arm: leaving it out would let the plan escalate
past an artifact form that met the same gate. R0 is a G0 exit, not a family member. R3b
(DeBERTa-v3-large) runs only if the §4.4 parity checks pass, and ships labeled "untested in 0.8.0"
otherwise. R4 is a documented escalation, untested.

## Tasks

**T1** (generated, code-labeled) is `fixture_evidence_only`. It informs the guard text — NOTA,
twins, negation — and makes **no margin claim**. A synthesized program scored on code-computed
labels from its own family is circular, which is exactly why T1 cannot carry A1.

Real-text confirmation, all human-written, seeded equal-probability splits:

| Task | Data | Confirmation n | Cost matrix | Powered to σ̂ ≤ |
| --- | --- | --- | --- | --- |
| T2a | BANKING77, 77-way, CC BY 4.0, about 13.1k | about 6,000 | misroute 1, abstain 0.3, correct 0 | 0.09 |
| T2b | CLINC150 + OOS, route-or-abstain, reusing E1's seeded partition | 12,850 | the same | 0.20 |
| T2c | CivilComments, the E1-disjoint 100k pool | 40,000, expanded to 60,000 **by the analysis-lock n(σ̂) rule, not by discretion** | C_FP:C_FN = 1:4 | 0.53538055 |

n at equality with 80% power on the one-sided NI event, K = 6 [Rep, `calc_v4.py` §4]: **6,354**
(σ = 0.10), **12,698** (0.20), **22,467** (0.30). Fable's estimate that a 77-way task disagreeing
on 7% of rows has σ ≈ 0.26 makes **T2a likely unpowered**, which is stated here in advance so the
result is not read as a surprise.

Tasks combine by intersection-union, so no cross-task correction is needed. "Powered" is per
contrast: an outcome row quantified over tasks means powered for that row's own contrast.

## Outcome rows

| Row | Condition |
| --- | --- |
| **Stop at a low rung** | One low rung is non-inferior on every powered real task, and at least 2 tasks are powered. The recipe names the artifact form that sufficed and the task type |
| **Narrowed** | The same with only 1 powered task. The recipe names that task type only |
| **Escalate** | R3a superior to every low rung by more than 0.01 on a powered task |
| **Workload-local** | Mixed results across powered tasks |
| **Inconclusive** | Everything else, including no powered task. **No rung recommendation**: the default stays the procedure, and the recipe states that the 0.8.0 reproduction was inconclusive at 1 pp |

## What is predicted in advance

**P11: programs lose on fuzzy real text**, labeled [H]. A1 and the PAW arms are expected to do
worse than the model rungs on T2a–c. That is a placement result, not a defect, and it is written
here before the run so it cannot be reframed afterwards. RAP's reproduced table establishes
artifact-form ordering **on synthetic contrast pairs only** and cannot establish this.

## Provenance and compute

Every example is generated by local open weights. **No Jev output enters any training path**, and
the provenance gate runs on the graph before the arms are fit. The PAW arms use the local compiler
and a local teacher; hosted compile is a fallback with public data only, unused by default.

GPU budgets: R1 6 GiB, SetFit/DeBERTa 10 GiB, **A2b 38 GiB with a 9 GiB local teacher, so its
aggregate admission is 77 GiB**. Cap 24 GPU-h. The Qwen3.5 linear-attention parity check must pass
before R1 runs; if it fails, Qwen3-1.7B becomes the R1 model and the receipt records the swap.
