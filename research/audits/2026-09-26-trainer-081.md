The following CPU fixture checks the numerical rationale of the fit guidance,
not RSI-Jev's implementation or a real application's optimizer. It deliberately
compares a head-only optimizer with the intended full-parameter optimizer.
Executed by extracting this Python block and passing it to `exec` with Python
3.11 and preinstalled torch 2.14.0+cpu. Output: head-only tower moved **False**;
full-optimizer tower moved **True**; fitted probabilities **0.3** for the soft
target and **0.00403698** for hard zero. All assertions passed. Torch warned that
NumPy was unavailable; this fixture uses no NumPy conversion and completed.

```python
import torch
from torch import nn
from torch.nn import functional as F

torch.manual_seed(17)
for full in (False, True):
    tower = nn.Linear(1, 1, bias=False)
    head = nn.Linear(1, 1, bias=False)
    with torch.no_grad():
        tower.weight.fill_(1)
        head.weight.fill_(1)
    params = list(tower.parameters()) + list(head.parameters()) if full else list(head.parameters())
    optimizer = torch.optim.SGD(params, lr=.1)
    before = tower.weight.detach().clone()
    loss = F.binary_cross_entropy_with_logits(head(tower(torch.tensor([[.4]]))), torch.tensor([[.7]]))
    loss.backward()
    assert torch.isfinite(tower.weight.grad).all() and tower.weight.grad.abs().sum() > 0
    optimizer.step()
    moved = not torch.equal(before, tower.weight)
    assert moved == full  # requires_grad and a gradient are insufficient.
    print('full optimizer:', full, 'tower moved:', moved)

for target in (.3, 0.):
    z = nn.Parameter(torch.tensor(0., dtype=torch.float64))
    optimizer = torch.optim.SGD([z], lr=.5)
    for _ in range(500):
        optimizer.zero_grad()
        loss = F.binary_cross_entropy_with_logits(z, torch.tensor(target, dtype=torch.float64))
        loss.backward()
        optimizer.step()
    p = z.sigmoid().item()
    if target == .3:
        assert abs(p - .3) < 1e-8
    else:
        assert p < .01  # Hardening the label changes the target, not just speed.
    print('target:', target, 'fitted:', round(p, 8))
```
