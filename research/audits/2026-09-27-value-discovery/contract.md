# Value discovery: qualify inputs, test the evaluator, then compare

Authorized by the user's request to execute an honest value investigation with
oracle consultation. This is research, not a release or production activation.
Current skill is frozen at 686e5f613da0516643677af01e5b83131788d28d,
0.8.2-dev. No guidance changes during this campaign; published 0.8.1 unchanged.

## Decision and alternative explanations

Question: does explicitly loaded Augustus improve an application's realized
decision loss or report validity relative to the same agent without Augustus,
and relative to a short generic reminder? Prior exact-code acceptance ties cannot
distinguish strong baselines, weak treatment, and insensitive measurement.
Neither finding a failure nor obtaining a skill win is required for completion.

Oracle recommended client-wire isolation tests, baseline-only failure discovery,
continuous application outcomes, an active reminder control, and protected
transfer. Coordinator rejects changing normal global configuration to plant
sentinels, treating self-reported split IDs as independence proof, pooling distinct
task losses for a significance claim, or compressing the skill solely because
one small task ties with a reminder. These are hypotheses to test, not conclusions.

## Isolation qualification, before inference

Use the existing Mac/VibeProxy execution environment with exact build identity.
Run offline mock endpoints with full request capture, negative synthetic user/
ancestor sentinels and positive plugin sentinels in disposable paths only.
Inspect actual system/messages/tool descriptions, not just skill inventories.
Record managed-settings presence/hash; the ineffective override environment
variable is not evidence. Inventory bundled instructions common to all arms.
Test post-proxy behavior against an isolated mock upstream if feasible; otherwise
state the unverified layer and do not certify end-to-end isolation. Proxy restarts
per inference attempt. Do not expose credentials or private personal instructions.
Unexpected injection or an unresolved material isolation defect stops inference.

## Instrument and discovery

Independent author receives no installed skill contents or prior agent answers.
Two development briefs require fitting/choosing a system from messy operational
records with factual provenance and feature-availability documentation. Objective
future-cohort loss, serving constraints, and recomputed report arithmetic are
separate outcomes. No prescribed method, process checklist reward or prose judge.
Validate careful, minimal no-ceremony and plausible careless implementations,
independent arithmetic anchors and at least five meaningful mutants. Parent
reruns validation before agent execution. Synthetic data remains labeled synthetic.

Freeze a different-domain transfer packet before discovery; leave it unopened.
Run two fresh baseline attempts on each development task (four total). These are
discovery observations, excluded from any later comparison estimates. If neither
task shows consequential outcome/report failure, stop and retain the null. Do not
weaken the model, tighten grading, or modify tasks after seeing baseline results.

## Conditional comparison and transfer

If discovery identifies a measurable opportunity, freeze task-specific comparison
criteria before new attempts. Controls: no Augustus; generic reminder; explicitly
loaded frozen trainer. Reminder text: "Check which fields exist at decision time;
validate on later records than you fit on, and bind reported metrics to the
population they describe." Same prompt otherwise; same tools and budgets.
Three fresh repetitions per task/arm, up to eighteen comparison attempts.
Rotate order and preserve all attempts. Continuous losses stay in each task's
units. Report arithmetic and hard constraints cannot be traded away for loss.
No population-level significance claims from two constructed applications.
Only a descriptive benefit meeting the frozen criteria proceeds to the protected
transfer (two repetitions per arm, six attempts). No optimizing after opening it.
Tie, harm or mechanism noncoverage remain valid outcomes, not gates to rewrite.

## Budgets, custody and stopping

Same requested/reported Opus 5.5 medium through existing VibeProxy; no silent
substitution. Forty turns/600 seconds per attempt, concurrency one. New reported
cost ceiling $15 total: at most $3 discovery, $9 comparison, $3 transfer. Check
before every launch; one in-flight overshoot possible. Unknown cost/outcome stops
launches until reconciled; no automatic retries. No rental or additional provider.
Full comparison requests should be captured safely for input auditing, with
credential headers excluded. Preserve failures, timeouts, raw outputs, costs,
artifact hashes and grading evidence. Private graders remain outside task agents'
access. Operator can inspect development graders, never use them to help agents.
No background campaign continues after the bounded experiment finishes.
