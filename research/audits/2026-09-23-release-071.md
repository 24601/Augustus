### Coordinator reading of the answers

The coordinator read all 38 answers. Recomputed figures all hold:

- entropy of (0.6, 0.1, 0.1, 0.1, 0.1) ≈ 1.77 bits;
- the 74.5% deferred-slice hypothetical;
- the Bonferroni bound of 28.5% and 668 cases per category;
- Clopper–Pearson 88.7–98.4% for 95/100 and 6.2% for 2/100;
- the temperature-scaling logit examples.

All three non-trigger controls answered without the skill. Both Fable revise
notes concern answer wording, not the skill text:

- an unnamed weak-to-strong citation in `distillation_errors`;
- a missing family-wise note in `audit_sample`.

The blind comparison's one loss (portfolio) led to a wording change. The
one-off step now names sensitivity to uncertain estimates as well as weights.

### Activation A/B and decision

Pre-registered rule: adopt the new description only if near-miss firing does
not increase, no near-miss reaches 2/3, and should-trigger firing does not
decrease.

The proposal fixed two real misses: a reranker score read as a probability, and
done-check design, each 0/3 to 3/3. It failed the rule, so 0.7.1 keeps the
current description. Both arms miss joint-check arithmetic and a non-software
portfolio prompt. Revisiting the description needs a fresh held-out query set;
reusing these 20 queries would tune on the test.
